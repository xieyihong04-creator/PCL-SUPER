# Windows 实机验收清单（PCL SUPER 预发布）

本清单用于在 Windows 实机上逐项确认移植功能。当前源码在 Linux 上交叉编译通过、415 项迁移测试通过，
但**尚未在任何 Windows 机器上运行过**，以下每一步都需要人工确认。

运行环境：Windows 10/11 x64，需安装 .NET 10 Desktop Runtime（预发布包为框架依赖发布）。
建议先备份 `PCL` 配置目录，并用一个测试实例验收。

## 1. 启动与品牌

- [ ] 双击 `Plain Craft Launcher 2.exe` 能正常启动，无缺失 DLL 报错
- [ ] 标题栏显示 `PCL SUPER`
- [ ] 设置 → 关于 显示 `PCL SUPER` 与版本号

## 2. 首页

- [ ] 首页出现「继续上次的世界」卡片，显示最近存档名称与时间
- [ ] 点击后能直接进入该世界（版本不支持 QuickPlay 时卡片应隐藏）
- [ ] 切换实例后卡片内容随之刷新

## 3. 实例页

- [ ] 实例管理卡片显示「整合包模式：开/关」「更新清单」「整合包更新」
- [ ] 开启整合包模式后，资源页隐藏「安装本地资源」「下载新资源」并显示说明
- [ ] 关闭后资源页恢复原状
- [ ] 「更新清单」填写非 https 地址会被拒绝；留空并确定会隐藏「检查更新」
- [ ] 「检查更新」在无网络/错误 JSON 时只弹提示，不影响手动更新

## 4. 整合包更新

准备：两个版本的整合包（新版可含增删改文件）。

- [ ] 本地文件更新：选旧包→选新包→差异预览→确认→更新成功
- [ ] 直链更新：选择「下载链接」，粘贴直链能下载并继续
- [ ] 个人修改的文件在预览中列为「保留」，更新后内容未被覆盖
- [ ] 更新前自动生成「整合包更新前」还原点
- [ ] Minecraft/加载器版本不同的包会被拒绝，并给出说明
- [ ] 更新完成后「整合包模式」自动开启
- [ ] 作者清单检查：填写真实 HTTPS JSON，版本相同提示已是最新；版本不同走预览与确认

## 5. 资源页

- [ ] 更新任一 Mod 前自动保存「更新模组前」还原点（实例页→还原点可见）
- [ ] 依赖关系图可打开，未满足依赖标红，点击显示详情
- [ ] 按键设置能读取 options.txt、修改并写回；游戏运行时拒绝修改

## 6. 存档页

- [ ] 「导入存档压缩包」可多选 `.zip`，成功提示世界名
- [ ] 含多个 `level.dat` 或越界路径的压缩包被拒绝，原存档不受影响
- [ ] 与现有存档重名时自动生成 `名称 (2)`，不覆盖
- [ ] 导入后存档列表自动刷新

## 7. 导出页

- [ ] 默认勾选「导出时隔离存档」，存档选项隐藏
- [ ] 导出的整合包解压后**不含** `saves/`
- [ ] 取消隔离后存档选项出现，勾选后导出包含 `saves/`
- [ ] 载入含 `saves/` 规则的外部导出配置时，隔离开启状态下该规则被忽略

## 8. 其他

- [ ] 还原点：创建、恢复、删除均正常
- [ ] 测试副本：创建、迁移测试环境正常
- [ ] 版本下载：任意地区网络下可正常下载 Minecraft 与加载器（地区限制已移除）
- [ ] 启动游戏、崩溃分析与日志无新增异常
